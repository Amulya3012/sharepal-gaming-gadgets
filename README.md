# SharePal Gaming Gadgets — Frontend Recreation

A responsive React/Vite recreation of SharePal's Bangalore gaming-gadgets rental category page, created as a frontend assignment.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Features
- Responsive SharePal-inspired navigation and category page
- Rental date selector
- Product category filtering
- Wishlist interactions
- Product hover states
- FAQ accordion
- Testimonial carousel
- Responsive mobile menu
- Scroll-to-section navigation
- SharePal-inspired promise, metrics and related-category sections

## Note
This is an independent frontend recreation. Product imagery and content are used as demonstration/mock content; no proprietary backend or checkout functionality is included.
